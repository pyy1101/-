URL 编码解码

在线 URL 编码解码工具，支持 encodeURIComponent 和 decodeURIComponent

关于URL 编码解码

URL 编码（百分号编码）是将 URL 中的特殊字符转换为 %xx 格式的标准方法。当 URL 参数中包含中文、空格或特殊符号时，必须进行编码才能在网络上正确传输。本工具提供 URL 编码和解码功能，输入原始文本即可得到编码后的 URL 安全字符串，反之亦然。支持完整的 encodeURIComponent 规范，适用于前端开发、API 调用、爬虫等所有需要处理 URL 的场景。
