关于HTML 转 Markdown

HTML 转 Markdown 是内容迁移和文档整理中的常见需求。当从网页上复制格式化文本、将旧的 HTML 博客迁移到 Markdown 平台（如 GitHub Pages、Notion）、或者清洗富文本编辑器输出时，都需要将 HTML 转换为简洁的 Markdown 格式。本工具支持所有常见 HTML 标签到 Markdown 的转换，包括标题、加粗、斜体、链接、图片、列表、代码块和引用等。
